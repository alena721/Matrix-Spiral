# Matrix Spiral

Библиотека для тестового задания: асинхронно скачивает квадратную матрицу
по HTTP(S) и возвращает её элементы списком, обходя по спирали
против часовой стрелки, начиная с левого верхнего угла.

## Задание

Тестовое задание Avito: [python-trainee-assignment](https://github.com/avito-tech/python-trainee-assignment)

## Что сделано

- `async def get_matrix(url: str) -> List[int]` — интерфейс по ТЗ.
- Загрузка реализована асинхронно: стандартная библиотека (`urllib`)
  с выносом блокирующего вызова в отдельный поток через
  `asyncio.get_running_loop().run_in_executor`, поэтому цикл событий
  не блокируется.
- Спиральный обход против часовой стрелки от левого верхнего угла.
- Работает на квадратных матрицах любой размерности (проверено на 1×1-4×4).
- Проверка квадратности матрицы: несовпадение длин строк → `MatrixError`.
- Обработка ошибок сервера и сети - всё сводится к `MatrixError`.
- 8 юнит-тестов: test case из задания, размерности, Connection Refused, пустой URL.
- Type hints и докстринги на всех функциях.
  
Уточнения:
- Тест `test_from_source` загружает матрицу по URL из задания
  и требует доступа в интернет. Остальные тесты работают офлайн.
- **Обработка нечисловой ячейки.** Если в таблице окажется `| abc |`,
  выпадет `ValueError`, а не `MatrixError` — ошибка не сведется к общему типу.
- **Задание фиксирует формат таблицы**, посторонние строки игнорируются.

## Что не сделано

- **Повторные попытки при сбоях сети** — при единичной загрузке матрицы
  избыточны.
- **Тесты на ошибки сервера и ожидание ответа от сервера** — обработка есть в коде, тесты не написаны


## Как запустить

## Установка

# 1. Активировали виртуальное окружение
~\manimations\.venv\Scripts\activate

# 2. Попытка установки обычным pip:
pip install aiohttp
python -m pip install aiohttp   # если ответ: No module named pip (в uv-окружении pip нет)

# 3. Установка через uv:
uv pip install aiohttp          # поставила aiohttp 3.14.5 + 8 зависимостей

# 4. Переход в папку проекта
cd C:\

# 5. Проверка
python -c "import aiohttp; print('ok', aiohttp.__version__)"

# 6. Прогон тестов
python -m unittest test_matrix -v   # 8 тестов

## Запуск тестов

cd "C:\..."                                              
C:\...> python -m unittest test_matrix -v
