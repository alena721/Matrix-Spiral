# Matrix Spiral

Библиотека для тестового задания: асинхронно скачивает квадратную матрицу
по HTTP(S) и возвращает её элементы списком, обходя по спирали
против часовой стрелки, начиная с левого верхнего угла.

## Задание

Тестовое задание Avito: [python-trainee-assignment](https://github.com/avito-tech/python-trainee-assignment)

## Что сделано

- `async def get_matrix(url: str) -> List[int]` — интерфейс по ТЗ.
- Загрузка реализована асинхронно: стандартная библиотека (`urllib`)
  с выносом блокирующего вызова в отдельный поток через
  `asyncio.get_running_loop().run_in_executor`, поэтому цикл событий
  не блокируется.
- Спиральный обход против часовой стрелки от левого верхнего угла.
- Работает на квадратных матрицах любой размерности (проверено на 1×1-4×4).
- Проверка квадратности матрицы: несовпадение длин строк → `MatrixError`.
- Обработка ошибок сервера и сети - всё сводится к `MatrixError`.
- 8 юнит-тестов: test case из задания, размерности, Connection Refused, пустой URL.
- Type hints и докстринги на всех функциях.

## Что не сделано

- **Повторные попытки при сбоях сети** — при единичной загрузке матрицы
  избыточны.

## Как запустить

Требуется только Python 3.8+. Внешних зависимостей нет.

python -m unittest discover -v   # запуск тестов
